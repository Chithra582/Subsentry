# Cancellation Pathfinder Skill

## Overview
Empowers users to break through dark patterns and complicated cancellation funnels with step-by-step instructions.

## Operations
1. Retrieves verified, direct unsubscription links for identified vendors.
2. Outlines exact steps required to cancel recurring subscriptions via web or mobile apps.
3. Generates cancellation email drafts and support ticket templates for manual services.
4. Records user cancellation status to update financial burn projections.
